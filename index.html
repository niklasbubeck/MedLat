Plug and play.

MedLat (medlat) is a PyTorch library organised around four plug-and-play pieces — an autoencoder, a generator, an optional alignment module, and a denoising scheduler. Pick one of each, snap them together, and train. Works for 2D images and 3D medical volumes with no code changes.

Architecture

Four pieces. Any combination.

Every MedLat pipeline is assembled from the same four plug-and-play pieces. Swap any one of them without touching the others.

i.

Autoencoder / Tokenizer

Pixels in, latents out. Continuous KL autoencoders or discrete quantizers, 2D or 3D, any compression ratio.

ii.

Generator

Learns the distribution in latent space. Non-autoregressive diffusion, masked, or autoregressive — whichever suits the tokenizer.

iii.

Alignment Module

Optional. Reshapes the latent geometry around a frozen vision-foundation teacher so nearby codes are semantically nearby.

iv.

Denoising Scheduler

Drives the generator during training and sampling. Gaussian diffusion, flow matching, or self-flow — one unified factory.

GenWrapper is the outlet the four pieces snap into — it detects their types, wires the right encode / decode path, and validates the combination at construction so mismatches surface immediately.

Setup

Installation.

Core dependencies: PyTorch, NumPy, Einops, timm, OmegaConf, MONAI. Optional quantizer paths pull in extras lazily when needed. 

# Editable install from repo root
pip install -e .

# With dev extras (pytest, ruff, mypy, pre-commit)
pip install -e ".[dev]"

First five minutes

Quick start.

Discover a piece, build a tokenizer, snap a generator onto it, and let the registry fill in the mechanical kwargs. 

from medlat import (
    get_model, available_models, get_model_signature,
    suggest_generator_params, clone_with,
    GenWrapper, create_scheduler, available_schedulers,
)

# ── Discover ─────────────────────────────────────────────────────────
available_models("discrete.")          # filter by prefix
get_model_signature("dit.xl_2")         # see required kwargs

# ── Autoencoder + generator — params inferred automatically ────────
tok = get_model("continuous.aekl.f8_d16", img_size=224)
gen = get_model("dit.xl_2", img_size=224, num_classes=10,
                **suggest_generator_params(tok))  # → vae_stride=8, in_channels=16
wrapper = GenWrapper(gen, tok)
print(wrapper)                            # routing · models · scale_factor

# ── Tweak without rebuilding a config ───────────────────────────────
tok_hires = clone_with(tok, img_size=512)   # fresh instance, swap fields

# ── Denoising scheduler — discover, inspect, create ────────────────
available_schedulers()                        # ('diffusion', 'flow', 'self_flow')
sched = create_scheduler("flow", path_type="Linear", prediction="velocity")

# ── 3D volumes — same API ───────────────────────────────────────────
get_model("continuous.aekl.f8_d16", img_size=(64,128,128), dims=3)

Release notes

What's new in v0.1.4.

Four quiet improvements that together remove most of the friction in wiring the pieces together.

Inference

Stop guessing kwargs.

suggest_generator_params(tokenizer) returns the exact kwargs the paired generator needs — in_channels, vae_stride, codebook_size — derived directly from the autoencoder. 

gen = get_model("<generator-id>", img_size=256,
                num_classes=1000,
                **suggest_generator_params(tok))
Iterationnew

Clone & tweak.

Every piece built via get_model() now carries its config. clone_with(model, **overrides) rebuilds a fresh instance with fields swapped — no config dict to reassemble. 

tok       = get_model("<autoencoder-id>",
                      img_size=256)
tok_wide  = clone_with(tok, z_channels=16)
tok_hires = clone_with(tok_wide, img_size=512)
tok.config   # {'img_size': 256}
Safety

Actionable errors.

GenWrapper validates the pair at construction time and tells you exactly how to fix a mismatch — no silent crashes half-way through a training loop. 

# ValueError: Channel mismatch:
#   generator.in_channels=4 but autoencoder.embed_dim=16.
#   → Rebuild with in_channels=16, or pass
#     **suggest_generator_params(tokenizer)
Schedulingnew

Unified scheduler registry.

One medlat.scheduling package replaces the old diffusion and transport modules. Discover, inspect, and build denoising schedulers the same way you build the other three pieces. 

available_schedulers()
# → ('diffusion', 'flow', 'self_flow')
sched = create_scheduler("self_flow",
           masking_strategy="complexity")

Inside each piece

Deep dive.

A closer look at what each of the four pieces offers. Step through with the arrows, dots, or the left / right keys.

i.

Autoencoder / Tokenizer

Pixels in, latents out. The first stage compresses images or 3D volumes into a representation the generator can work with.

Two families live here. Continuous autoencoders keep the latent space smooth and differentiable — ideal pairing for diffusion generators. Discrete tokenizers quantise into a finite vocabulary — ideal for sequence-model generators.

What's available

  • Continuous KL autoencoders across a range of compression ratios and latent widths.
  • Discrete quantization schemes: vector, lookup-free, binary-spherical, finite-scalar, residual, and hybrid variants.
  • One-dimensional token sequences for sequence-model generation.
  • Every option supports 2D imagery and 3D volumetric data through the same API.
ii.

Generator

Learns the distribution of latents. Sampling a new image begins here.

Pick the family that matches the tokenizer. Diffusion and masked generators denoise or fill in parallel steps; autoregressive generators predict one latent at a time. Conditional and unconditional training are first-class.

What's available

  • Non-autoregressive diffusion — transformer and UNet backbones, with or without masked branches.
  • Continuous autoregressive — masked and recurrent variants, trained with a diffusion loss on continuous latents.
  • Discrete autoregressive — masked, causal, and BERT-style denoisers on token grids.
iii.

Alignment Module

Optional. Reshapes the latent geometry around a frozen vision-foundation teacher.

A reconstruction-only latent space is compact but geometrically opaque — nearby codes carry no semantic guarantee. Alignment adds a projection head and a Vision-Foundation loss that pulls the autoencoder toward the teacher's semantic structure. The teacher is frozen; only the projection head trains.

Teachers available

  • DINOv2-L — natural imagery, general vision.
  • MAE-L — self-supervised vision.
  • BiomedCLIP — medical imaging, recommended for radiology and pathology.
iv.

Denoising Scheduler

Drives the generator during training and sampling.

A unified factory exposes three paradigms side by side — discover and build them the same way you build the other three pieces: available_schedulers(), scheduler_info(name), create_scheduler(name, **kwargs).

Paradigms available

  • Gaussian diffusion — DDPM-style, with optional dimension-aware timestep shift for 3D volumes.
  • Flow matching — configurable paths and prediction targets.
  • Self-flow — masking-driven token denoising.
